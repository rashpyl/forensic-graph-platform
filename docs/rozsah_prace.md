# Rozsah práce

## 1. Teoretická část (2–3 týdny)

- Základní studium metod strojového učení relevantních pro daný projekt  
- Úvod do problematiky link prediction a práce s grafovými embeddingy  
- Přehled grafových databází a jejich srovnání s relačními databázemi  
- Příprava dat pro aplikaci
- Diskuse etických aspektů prediktivní kriminalistiky  

---

## 2. Návrh systému (2 týdny)

- Formální specifikace cíle a problému  
- Návrh grafového datového modelu (uzly, vztahy, atributy)  
- Návrh architektury systému (backend, databáze, frontend, ML modul)  
- Návrh API  

---

## 3. Implementace systému (6 týdnů)

- Implementace backendu a grafové databáze  
- Implementace mapové vizualizace  
- Implementace grafové vizualizace vztahů  
- Implementace základního statistického modulu   

---

## 4. ML komponenta predikce a experimenty (4–5 týdnů)

- Příprava dat  
- Implementace baseline metod (Common Neighbors, Adamic-Adar)  
- Implementace pokročilejší metody (Node2Vec + klasifikátor)  
- Vyhodnocení modelů (ROC-AUC, precision, recall)  

---

## 5. Vyhodnocení a finalizace práce (2–3 týdny)

- Testování a optimalizace systému  
- Interpretace výsledků  
- Závěrečná diskuse a sepsání finální verze práce  

---

**Celkový odhad:** 16–17 týdnů.
